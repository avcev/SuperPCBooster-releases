# Super PC Booster — wydania

Bezpieczna optymalizacja PC pod gry. Każdą zmianę można cofnąć.

## Pobierz
Najnowsza wersja: **Releases** (po prawej) → plik SuperPCBooster-x.y.z.zip → wypakuj → uruchom exe → przeczytaj INSTRUKCJA.txt.

## Aktualizacje
Zainstalowany program sam sprawdza to repozytorium i proponuje nowe wersje. Każda aktualizacja jest podpisana cyfrowo (update.json.sig), a plik sprawdzany sumą SHA-256 — zmieniony albo uszkodzony plik nigdy nie zostanie zainstalowany.

## Bezpieczeństwo
Program nie wyłącza Windows Update, Defendera ani zapory, nie usuwa Twoich plików i nie wysyła żadnych danych. Jedyne połączenie z internetem to sprawdzenie, czy jest nowa wersja.
